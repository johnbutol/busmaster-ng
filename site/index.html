  • Built with Visual Studio 2022; runs on Windows 7 to 11.
  • DBC databases load directly (CAN → Load DBC), and the DBC ↔ DBF converters are fixed.
  • Message window and Signal Watch show value descriptions of signals again.

  • Configurations of BUSMASTER 3.2.x open unchanged.

Frequently asked questions

Does BUSMASTER run on Windows 10 and Windows 11?

BUSMASTER-NG does: it runs on Windows 10 and 11 (32 or 64 bit) and on Windows 7 SP1. Take the installer, or a portable zip if you prefer no setup.

BUSMASTER 3.2.2 freezes on the splash screen. What can I do?

BUSMASTER 3.2.2 waits for its simulation engine, which is registered only when it is installed with administrator rights. BUSMASTER-NG registers it for the current user when needed, without administrator rights, and if it still cannot start, a message says why instead of a hang. A missing Microsoft Visual C++ 2013 runtime is also reported, with a link to the Microsoft download page.

How do I load a DBC file?

In BUSMASTER-NG choose CAN → Load DBC (Ctrl+Shift+M): the DBC files are converted and associated directly, several at once. The DBC ↔ DBF converters of the original BUSMASTER are fixed too.

Which CAN and LIN interfaces are supported?

PEAK, Vector XL, Kvaser, ETAS BOA, IXXAT VCI, MHS, VScom, Intrepid neoVI, NSI, i-VIEW and ISOLAR-EVE, like the original BUSMASTER. Install the driver of your interface from its manufacturer. The Simulation driver works without hardware.

Can I install it next to BUSMASTER 3.2.2?

Yes. BUSMASTER-NG keeps its settings apart from earlier versions, and configurations of BUSMASTER 3.2.x open unchanged.

Is it free, also for use at work?

Yes. BUSMASTER-NG is free and open source under the GNU LGPL v3, like the original: you can use it at home or in a company at no cost. If you distribute a modified version, share your changes under the same license.

Does it run on Linux or macOS?

No, BUSMASTER-NG is a Windows program (MFC). There is no Linux or macOS version.
